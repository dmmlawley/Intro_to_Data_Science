Weeks 2-3 · Interactive Data Science Studio

Explore real datasets with Python, Pandas and Seaborn thinking

This classroom-ready web app gives 16-18 year olds an interactive route into data science. Students choose a dataset, filter and sort records, review summary statistics, create visualisations, and critique how charts can support or mislead conclusions.

Week 2 focus

  • Import and explore datasets using Pandas ideas
  • Filter, sort and summarise data
  • Use descriptive statistics to answer research questions

Week 3 focus

  • Select bar charts, histograms and scatter plots
  • Spot trends, outliers and correlations
  • Evaluate whether a visualisation is fair or misleading

How pupils use it

  • Pick a dataset that interests them
  • Investigate a challenge question
  • Support conclusions with stats and charts

Week 2 · Exploring data with Pandas

Students work as data investigators rather than coders first. Each control in the workspace mirrors a common Pandas action.

Load data Filter rows Sort columns Describe values

Manual spreadsheet route: repeated filters, formulas and pivot tables. Python route: a small number of reusable Pandas commands.

Week 3 · Visualising patterns with Seaborn

Students test the same question with multiple chart types, then explain which visualisation best communicates the evidence.

Bar chart Histogram Scatter plot Peer review

The generated chart notes highlight bias risks such as hidden spread, chosen bins, and confusing correlation with causation.
